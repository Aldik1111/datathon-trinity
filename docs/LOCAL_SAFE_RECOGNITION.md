# Локальное распознавание состояния сейфа

Это первая обученная модель для изображения сейфа в указанной области. Она различает `open` и `closed`; `unknown` означает отказ при низкой оценке уверенности, а не обученный третий класс. Она не определяет заперт ли замок, наличие ключа, проверку личности, передачу денег или нарушение регламента. На незнакомых изображениях возможны уверенные ошибки.

## Использование

Откройте http://127.0.0.1:8501. Выберите «Локальные примеры», например Х-39.mov, либо загрузите MOV. Проверьте зелёную рамку: она должна охватывать сейф и пространство открывающейся дверцы. При необходимости поправьте X, Y, ширину и высоту в долях кадра. Подтвердите область и нажмите «Анализировать».

Результат содержит наблюдения через 0,5 секунды, интервалы открытого или неопределённого состояния и JPEG-кадры. Концы интервала обозначают первый и последний наблюдаемые кадры, а не точные границы действия между кадрами. `no_event` означает только отсутствие открытых/неопределённых состояний среди проверенных кадров, не отсутствие всех нарушений. `review_required` требует просмотра отмеченных участков.

Примеры train участвовали в обучении; val — в выборе параметров; test — только в итоговой проверке. Для быстрой демонстрации выбирайте Х-39.mov из test. Аннотации используются при подготовке обучающих примеров и калибровке области, но не передаются модели как готовые предсказания.

## Воспроизводимость

Python 3.12, `pip install -r requirements-ml.txt`. Исходные MOV и аннотации остаются вне Git.

```
python scripts/export_safe_dataset.py --help
python -m src.training.train_safe --manifest artifacts/safe-dataset/manifest.json --output artifacts/safe-model
python -m pytest
```

Используйте новый выходной каталог для нового обучения. Сохранённые model.npz/metadata.json/report.json относятся к одному запуску; не меняйте порог по test и не называйте повторную настройку независимой проверкой. Скрипт проверяет разделение по video_id и SHA256 группы. Экспорт использует одни и те же статические области на всех кадрах видео; копии исходников не расходятся между выборками.

Для воспроизведения текущего экспорта в подготовленной папке:

```
python scripts/export_safe_dataset.py --snapshot ../../outputs/annotations-after-batch.json --media-root ../batch-reference --output artifacts/safe-dataset-new
```

## Подключение к сервису

Создайте `.env` командой `python scripts/init_env.py`, сохранив сгенерированный ключ локально. Параметры модели:

```
ANALYZER_MODE=real
ANALYZER_CALLABLE=src.vision.safe_classifier:analyze_video
MODEL_PATH=artifacts/safe-model
SAFE_DATASET_MANIFEST=artifacts/safe-dataset/manifest.json
SAFE_MODEL_REPORT=artifacts/safe-model/report.json
```

При переносе на другой компьютер локальные примеры нужно заново экспортировать или указать новый manifest. Для загрузки собственных MOV manifest не требуется.

`POST /api/v1/analyze` принимает обычное поле file и дополнительное multipart-поле roi с JSON `[x,y,width,height]`. Оно обязательно для анализатора сейфа. Координаты нормированы относительно отображаемого, повёрнутого кадра. Временная калибровка и видео удаляются после обработки или ошибки. API использует локальный X-API-Key и слушает только 127.0.0.1.

Результаты хранятся в SQLite; подготовленная конфигурация сохраняет их 7 дней. Скачанный JSON остаётся до ручного удаления. Остановка/перезапуск приложения сохраняет готовые задания, но прерывает текущие.

## Результаты первого запуска

95 кадров из 14 уникальных видео: train57, val19, test19. Частично заслонённые кадры исключены; 17 меток повторяющихся копий не дублируются. Test содержит 15 закрытых и 4 открытых состояния из 3 видео. Кадры внутри видео коррелируют: это не 19 независимых сцен.

До отказа по уверенности: 18/19 верных состояний; матрица closed/open `[[14,1],[0,4]]`. Precision открытого состояния 0,80, recall1,00, F1≈0,889. Порог0,7 выбран только на val. С ним 4/19 кадров помечены неизвестными; оставшиеся15 определены верно. Малое число примеров не даёт гарантии такого качества на новых видео. Это кадровая оценка состояния; качество обнаружения нарушений и точных интервалов не измерено.

Полный проход X-39 через API: 158 кадров, открыто15/закрыто140/неопределённо3; открытые участки30,5–33,5с и67–70,5с. X-26:40 кадров, закрыто31/неопределённо9, открытых нет. Модель и порог после этих просмотров не менялись.
