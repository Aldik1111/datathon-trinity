# Аудит сервиса участника 3 — 17 октября 2026

Работа начата новым клонированием очищенного main, база
`d47d57b251ba24193662da4d80724a114ba46adf`. История этой базы содержит один коммит.
Предыдущие checkout, ветки и материалы ZIP не использовались. Входы тестов —
искусственные таблицы, JPEG и MOV, создаваемые кодом во временных каталогах.

## Фактическое состояние на старте

Существовали FastAPI, Streamlit, SQLite, однопоточная очередь с отдельным процессом
анализа, адаптер и тесты. На свежем окружении прошли 39 тестов.
Реального анализатора нет, `configs/rules.json` содержит пустой список.

## Изменения

- Передача результата от дочернего процесса через ограниченный локальный файл:
  контроль тайм-аута больше не зависит от потенциально блокирующего pipe recv.
  Общий размер доказательств ограничен 12 MiB JPEG; JSON-передача — 20 MiB.
- Подавление stdout/stderr анализатора и декодера в дочернем процессе. Ключ API
  не передаётся ему в Settings, API_KEY/API_KEY_FILE удаляются из его окружения.
- Удаление созданных сервисом файлов после ошибок/остановки, очистка UUID-сирот
  при запуске, secure_delete для удаляемых результатов SQLite.
- Явный тестовый заголовок demo вместо обычного сообщения об обнаружении.
  Проверка rule_status в UI; 404 результата завершает опрос вместо бесконечных повторов.
- Чтение API-ключа из secret-файла, health endpoint без данных, шаблон Docker Compose,
  HTTPS/Basic Auth gateway для последующего согласованного развёртывания.
- Документация передачи модели и правил, генератор синтетического MOV, CI для
  Windows/Linux и проверка сборки контейнера в Linux CI.

## Проверки

Среда локального аудита: Windows, Python 3.12, новое `.venv`.

```text
python -m pytest tests -q  → 55 passed
python -m pip check       → No broken requirements found
```

Проверены:

- Оба маршрута, ключ до чтения тела, неверный ключ, 404, пустой файл, расширение,
  превышение размера включая chunked-запрос без Content-Length.
- Очередь при конкурентных запросах, ожидание в общем временном бюджете,
  killable timeout, остановка с активной/ожидающей задачей, перезапуск и TTL.
- Отсутствующий анализатор → failed без отрицательного вердикта.
- JPEG/base64, несколько событий, времена, согласованность verdict/events,
  состояние нормативного источника, demo и ошибки в Streamlit AppTest.
- Отдельный живой HTTP-сервер + отдельный spawn-анализатор на синтетическом MOV.
  Сервер теста остановлен после проверки; сервис не оставлен опубликованным.
- Маркер искусственного «приватного» сообщения не выходит из логов/ошибок анализатора.
- Структурные проверки Compose: только loopback-порты в локальной конфигурации,
  внутренняя сеть API/UI, файловые секреты, allowlist COPY в Dockerfile.

Есть одно предупреждение Starlette о deprecated TestClient-адаптере httpx.
Оно не является ошибкой приложения. Тесты завершаются успешно.

## Точный статус готовности

**Техническая интеграция на синтетических данных проверена.** Реальный анализатор,
его скорость, точность, устойчивость к ракурсу и нормативные соответствия не проверены.
Готова конфигурация развёртывания, но Docker/TLS здесь не запускались: Docker
отсутствует. Результат удалённого CI следует проверять отдельно после публикации ветки.
Публичный URL, сервер и платные ресурсы не создавались.
